# Python Text Chunking Strategies

This example demonstrates three fundamental text chunking strategies in Python, crucial for Retrieval Augmented Generation (RAG) applications. It includes fixed-size chunking, fixed-size chunking with overlap, and a basic sentence-aware chunking method. The code illustrates how to break down a large text into smaller, manageable pieces suitable for LLM context windows.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
